# Security policy

Sandtable runs Claude Code sessions that can read and change your repos, and it stores Jira API
tokens encrypted with a key from the macOS keychain. Reports about either are welcome.

## Report a vulnerability

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/ashmanto/sandtable/security/advisories/new).
Don't open a public issue for it.

Include the Sandtable version or commit, what you did, and what happened. You get a reply within
a week.

## Supported versions

Only the latest commit on `master` gets security fixes.
